# Hands-On Machine Learning

This repository contains my implementations and notes while learning **Machine Learning and Deep Learning** through *Hands-On Machine Learning* by Aurélien Géron.

The concepts are implemented using **Scikit-Learn and PyTorch**, with Jupyter Notebooks for experimentation, visualization, and hands-on practice.
