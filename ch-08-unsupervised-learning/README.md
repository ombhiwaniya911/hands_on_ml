# Chapter 8: Unsupervised Learning

This chapter explores **Unsupervised Learning**, a machine learning approach that discovers hidden patterns, structures, and relationships in data without relying on labeled outputs.

This repository contains my notes, implementations, and experiments while studying *Hands-On Machine Learning with Scikit-Learn and PyTorch* by Aurélien Géron.

## 📚 Topics Covered

- **Clustering**
  - K-Means Clustering
  - DBSCAN
  - Hierarchical Clustering
  - Gaussian Mixture Models (GMM)
- **Clustering Applications**
  - Discovering groups and patterns in datasets
  - Comparing clustering algorithms
  - Visualizing cluster assignments
- **Anomaly Detection**
  - Identifying unusual observations
  - Understanding density-based approaches
- **Model Evaluation**
  - Evaluating clustering quality
  - Understanding cluster assignments and decision boundaries

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-Learn
- Jupyter Notebook
